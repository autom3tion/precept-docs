Precept.Dashboard

A page on your own machine that shows local Precept runs as they happen: each test as it starts and finishes, its retries, its log as it is written, and a live view of the Chromium page it drives. Run your suite headless and still follow its tests and their logs.

It also lists the test projects on your machine. Open one to see its tests, then run one test, a suite or all of them in the environment you pick, and watch them pass or fail in place.

This is a tool, not a library. Nothing in your test code references it.

dotnet tool install --global Precept.Dashboard
precept-dashboard

It opens a link with a key; the page opens only with that key. Add the folder that holds your test projects, leave it running, and run your tests as usual. The dashboard finds the runs of the projects on its list and keeps them for 90 days. A run knows nothing about it.

See Watching a run for what it shows and keeps, and Projects for running tests from it.
